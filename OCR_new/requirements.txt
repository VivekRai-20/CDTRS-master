# =============================================================================
# requirements.txt
# Offline OCR & Document Intelligence Engine (OCR_new)
# =============================================================================
#
# These pins are identical to imp.txt, the package set installed on the CDTRS
# PC (Python 3.12, 64-bit, installed per user).  Nothing needs to be installed
# for CDTRS: the packages are already there.  Do not add packages that are not
# in imp.txt.
#
# Python: 3.12 (64-bit).  PaddlePaddle 2.6.2 does not support Python 3.13+.
#
# Setting up another PC (needs internet):
#   python -m pip install -r requirements.txt
# The spaCy model en_core_web_sm 3.8.0 is also part of imp.txt; it is not
# listed here.
#
# OCR: PaddleOCR 2.8.1 on paddlepaddle 2.6.2, CPU only (config.yaml:
# paddleocr.use_gpu: false).  PaddleOCR 3.x is not supported.  The PaddleOCR
# models are in models/paddleocr/ (tracked in git; check with
# python setup_models.py --check).
#
# PDF rendering: pypdfium2 first, then PyMuPDF; both are self-contained.
# pdf2image is only a last fallback and needs Poppler (config.yaml:
# pdf.poppler_path).
#
# Tests use the standard library's unittest (no pytest):
#   python -m unittest discover -s testing -t . -v
# =============================================================================
